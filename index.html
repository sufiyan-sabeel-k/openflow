FAQ

What does OpenFlow do?

Converts text up to 2,500 characters into speech via Sarvam AI Bulbul v3 through a secure server-side backend.

Why doesn't generation work here?

This is the static GitHub Pages demo. Real generation needs generate.php + MySQL + Sarvam key on a PHP host. GitHub Pages cannot run PHP.

What happens to my audio?

On the PHP host, files save under uploads/audio/ and show only in your own history. See Privacy Policy.
