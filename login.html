FAQ

Does login work on this demo?

No. Real login (Google OAuth + mobile OTP) runs on the PHP backend with MySQL. This page only demonstrates the UI.

Where is the full app?

Deploy index.php/login.php/generate.php on a PHP host (see repo README), then configure Google redirect URIs and API keys server-side.
